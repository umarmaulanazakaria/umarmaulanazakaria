### Engineering Highlights

- A shared Express REST API and PostgreSQL database serving three applications.
- Prisma ORM for structured database access and transactional business workflows.
- Socket.IO notifications with REST and the database as the source of truth; clients refetch after changes and reconnects.
- Multi-service booking with quantities, scheduling validation, and rescheduling.
- Staff check-in, final barber assignment, and service lifecycle management.
- Midtrans Sandbox checkout with server-side webhook signature and provider-status verification.
- Separate customer and operator authentication, role-based authorization, and ownership checks.
- Automated tests for API workflows, concurrency, payment idempotency, realtime, and Web interactions; native UI evidence is tracked separately.

**Project status:** Demo ready with documented limitations. Educational and portfolio use only, not a production barbershop service.

Real email delivery is not enabled, a historical refund has no proven final provider status, dependency advisories remain open, and detailed native-device acceptance is not fully documented. See the [demo acceptance report](https://github.com/umarmaulanazakaria/barberbarbar/blob/main/docs/DEMO-ACCEPTANCE.md) for evidence and boundaries.
